작업 과정을 작은 공장에 비유해 보겠습니다. 당신은 주문서에 “이런 결과가 필요해요”라고 적습니다. 공장 안에서는 주문서가 조사대, 제작대, 검사대, 기록대를 차례로 지나갑니다. 당신이 각 기계를 직접 돌릴 필요는 없습니다.

여기서 “자동으로 했다”는 말은 컴퓨터가 혼자 영원히 일했다는 뜻이 아닙니다. 당신이 요청을 줄 때마다 내가 다음 안전한 작업을 판단하고, 필요한 파일을 찾고, 코드를 고치고, 테스트하고, 결과를 기록했다는 뜻입니다. 큰 선택이 필요할 때만 다시 확인합니다.

자료 조사, 작업표 작성, 파일 수정, 파서 연결, 화면 제작, 실패 방지, 테스트, 실제 서버 확인, 완료 시각 기록을 처리했습니다.

요청은 작업 공장을 통과했습니다

한 요청이 들어오면 바로 코드를 쓰지 않았습니다. 먼저 작업표에 올리고, 근거를 찾고, 만든 뒤, 검사하고, 기록했습니다.

  1. 접수: 요청을 작고 확인 가능한 일로 나눕니다.
  2. 조사: 공식 문서와 현재 코드를 읽어 무엇이 맞는지 확인합니다.
  3. 제작: 서버, 샘플, 렌더러와 문서를 수정합니다.
  4. 검사: 자동 테스트와 실제 서버 요청으로 결과를 확인합니다.
  5. 기록: 통과한 일만 체크하고 완료 시각을 남깁니다.
